# Example — Diagnostics

**Diagnostics Example** is a complete, built-in diagnostic project. Select it from Project Sessions to explore a compact real project with four one-run studies, its Wentelteef test setup, and the attached dataset files.

It is useful for learning the questionnaire flow, test-setup configuration, and project export/import. The project is supplied as a complete ISA-PHM project archive, so attached files are available after the example is loaded.

For a multi-run prognostics project, see [XJTU-SY Bearing Datasets](./EXAMPLE_XJTU_SY.md).
