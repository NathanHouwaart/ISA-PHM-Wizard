# Example — XJTU-SY Bearing Datasets

**XJTU-SY Bearing Datasets** is the built-in prognostics example. It contains 15 bearing studies and 9,216 runs, making it a realistic example of a large run-to-failure dataset.

Select it from Project Sessions when you need an example of multi-run studies, raw-data-only output, bearing configurations, and a substantial dataset attachment set. It is loaded from a complete ISA-PHM project archive only when selected, rather than being included in the initial application state.

For the smaller diagnostic example, see [Diagnostics Example](./EXAMPLE_DIAGNOSTICS.md).
